Help with your tracker.

For general technical or privacy questions, use the SwahaMoneyTracker public support repository.

Public support is visible to everyone. Never post account numbers, financial records, backup files, passwords, app PINs or signing keys. Crop or blur private details in screenshots. For a private question, use the user-support email displayed on Swaha’s Google permission screen.
Open Swaha support

What to include in a technical report

Share the app version, Android version, a short description of the problem and the steps that led to it. Include the error message with personal details removed. A financial backup file is not needed for an initial report.

Google backup

Connect the Google account you want to use in Settings → Google backup & restore. Enable daily backup and check the last verified upload time. During early access, only invited test accounts may be able to authorize the feature. Public availability will follow completion of the Google authorization rollout.

If a backup fails, check internet access, available Google storage and the status message in the app. Android may delay background work. A successful manual “Back up now” confirms a current upload; it does not prove that every future scheduled job will run.

Restore and device changes

Keep a local backup before uninstalling or changing devices. To restore from Drive, connect the same Google account and choose Restore latest Google backup. Check the preview before confirming; a restore replaces this device’s current ledger. Set up the app PIN on the new installation and enable daily backup again when ready.
